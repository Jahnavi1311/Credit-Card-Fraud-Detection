# Credit-Card-Fraud-Detection
Credit card fraud poses a major threat to digital transactions. Fraudulent activities are rare compared to legitimate ones, making the dataset highly imbalanced and challenging to model.  The objective of this project is to- Build a robust model using XGBoost, Handle class imbalance effectively and Evaluate model performance using suitable metrics
